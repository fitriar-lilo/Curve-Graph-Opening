Drawing Curves: Quadratic, Cubic and Reciprocal Graphs

Welcome! You do not need to be a maths expert to draw curves. If you can substitute a number into an equation, you can draw any graph on this page. We go one small step at a time.

1. How is a curve made?

A curve is a collection of many points (x, y) joined together. Each point comes from one value of x and the y-value the equation gives us. There are infinitely many points, so we plot a few and join them smoothly.

Demo with the equation y = x + 1. For x = −3, y = −3 + 1 = −2, so the point is (−3, −2).

2. Quadratic curves: y = ax² + bx + c

Here a, b, c are whole numbers and a is not 0. Our example is y = x² − 4. Fill in each y-value: square x first, then subtract 4. (Example: x = 3 gives 9 − 4 = 5.)

Remember: a negative number squared is positive, so (−2)² = 4.

Key parts of a quadratic curve

  • Shape: a parabola. If a is positive it is a U-shape; if a is negative it is an upside-down U.
  • Turning point (vertex): the lowest point (minimum) of a U or the highest point (maximum) of an upside-down U. Here it is (0, −4).
  • Roots (x-intercepts): where the curve meets the x-axis, so y = 0. Here x² − 4 = 0, so x = −2 and x = 2.
  • y-intercept: where the curve meets the y-axis, so x = 0. Here it is (0, −4).

Your analysis

Where is the turning point? What are the roots? Write what you notice.

Practice

1. For y = x² − 1, find y when x = 3.
2. For y = x² − 9, what is the y-coordinate of the turning point?
3. For y = x² − 9, what is the smaller root (x when y = 0)?

3. Cubic curves: y = ax³ + bx² + cx + d

Cubic curves have an x³ term. Our example is y = x³ − 4x. Cube x first (x × x × x), then subtract 4 times x. (Example: x = 2 gives 8 − 8 = 0.)

A negative number cubed stays negative: (−2)³ = −8.

Key parts of a cubic curve

  • Shape and flow: a stretched "S" shape. When a is positive, it rises on the right and falls on the left.
  • Turning points: up to two. One is a local maximum (a peak on the left, near x = −1) and one is a local minimum (a dip on the right, near x = 1).
  • Roots: up to three places where it crosses the x-axis. Here: x = −2, 0 and 2.

Your analysis

What happens to y as x gets very large (like 100)? And very small (like −100)?

Practice

1. For y = x³ − x, find y when x = 2.
2. For y = x³ − x, find y when x = −2.
3. For y = x³ − x, find y when x = 1. (This is also a root!)

4. Hyperbolic curves: y = a/x

Here x is in the bottom of a fraction. Our example is y = 6/x. Divide 6 by each x-value. (Example: x = −3 gives 6 ÷ (−3) = −2.) We cannot use x = 0 because you can never divide by 0.

Key parts of a hyperbola

  • Two branches: positive x-values give positive y-values (top right). Negative x-values give negative y-values (bottom left). No x-value connects them, so the graph splits into two separate curves.
  • Asymptote: a line the curve gets extremely close to but never touches or crosses. The y-axis (x = 0) is an asymptote because we cannot divide by zero. The x-axis (y = 0) is too, because 6 ÷ x is never exactly 0.

Your analysis

What happens to y as x gets closer and closer to 0? (Try x = 6, 3, 2, 1.)

Practice

1. For y = 12/x, find y when x = 3.
2. For y = 12/x, find y when x = −4.
3. For y = 4/x, find x when y = 2.
